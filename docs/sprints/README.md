## 🔄 Ciclo de Sprint (Metodología)

Seguimos el **Principio 2.2: Ciclos de Sprint (Agile)** definido en las reglas del proyecto:

### Inicio de Sprint
1. Calibrar el entorno (`git status`, verificar versión)
2. Revisar el estado actual del proyecto
3. Definir objetivos y tareas priorizadas

### Durante el Sprint
1. **Validar** → Proponer solución
2. **Implementar** → Código limpio
3. **Explicar** → Documentar cambios

### Cierre de Sprint
1. **Retrospectiva** → Análisis honesto (logros, calidad, deuda)
2. **Versión SemVer** → Determinar número de versión
3. **Consolidación** → Commit, tag, push a GitHub
